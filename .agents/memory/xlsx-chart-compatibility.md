---
name: Native Excel chart compatibility
description: Compatibility constraints for embedding native colored charts in generated XLSX files.
---

Native Excel charts can be embedded into a workbook generated by SheetJS by merging the chart package parts, worksheet drawing relationship, and chart formulas into the final XLSX ZIP. The legacy xlsx-chart package reliably generates multi-chart workbooks for column and bar charts; its pie chart path can fail during generation, so prefer column/bar charts unless the library is replaced.

**Why:** SheetJS Community Edition writes tables and styles but does not preserve or create chart objects, while the existing chart generator has an unreliable pie template.

**How to apply:** Generate the styled workbook first, generate chart XML from xlsx-chart, retarget chart formulas to the summary sheet, add per-point colors, and merge chart/drawing relationship parts without rewriting the workbook through SheetJS afterward.
