Проведи **только визуальный редизайн существующего интерфейса Electron-приложения для контроля договоров**.

**Не изменяй структуру и UX приложения.**

Не добавляй новые:

* элементы интерфейса;
* карточки;
* кнопки;
* поля;
* меню;
* разделы;
* графики;
* таблицы;
* виджеты;
* фильтры;

* информационные блоки.

**Не удаляй существующие элементы.**

**Не меняй их назначение.**

**Не меняй порядок элементов.**

**Не придумывай собственную структуру dashboard.**

Работай исключительно с тем интерфейсом, который уже существует в проекте.

Если в текущем интерфейсе есть 5 карточек — после редизайна должно остаться 5 карточек.

Если есть sidebar — оставь тот же sidebar.

Если есть таблица — оставь ту же таблицу.

Если есть кнопки — оставь те же кнопки.

Если есть поля — оставь те же поля.

Меняется **только внешний вид существующих элементов**.

---

# ВИЗУАЛЬНОЕ НАПРАВЛЕНИЕ

Переведи существующий интерфейс в современный **Premium Glassmorphism 2026**.

Ориентир по визуальному ощущению — предоставленный референс с glassmorphism-карточками.

Основные характеристики:

* dark glassmorphism;
* прозрачные поверхности;
* `backdrop-blur-md`;
* мягкое внутреннее свечение;
* очень тонкие границы;
* `border-white/10`;
* глубокий темный фон;
* мягкие ambient gradients;
* аккуратные teal / turquoise акценты;
* большие, но не чрезмерные скругления;
* минималистичные тени;
* визуальная глубина;
* премиальный desktop UI.

---

# GLASS-КАРТОЧКИ

Все **существующие карточки** приложения переработай в glassmorphism.

Базовый визуальный принцип:

```css
background: rgba(255, 255, 255, 0.05);
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);

border: 1px solid rgba(255, 255, 255, 0.10);

box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.07),
    inset 0 -1px 0 rgba(255, 255, 255, 0.02),
    0 12px 40px rgba(0, 0, 0, 0.15);

border-radius: 20px;
```

Не используй одинаковую интенсивность эффекта абсолютно для всех элементов.

Карточки должны иметь несколько уровней глубины, но при этом выглядеть как одна дизайн-система.

---

# BACKDROP BLUR

Основной glass-эффект строится вокруг:

```css
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);
```

Для крупных поверхностей допустимо использовать:

```css
backdrop-filter: blur(20px);
```

Для небольших элементов:

```css
backdrop-filter: blur(10px);
```

Blur должен быть **мягким и дорогим визуально**, без эффекта мутного стекла.

---

# ВНУТРЕННЕЕ СВЕЧЕНИЕ

Добавь очень тонкий inner highlight:

```css
box-shadow:
    inset 0 1px 0 rgba(255,255,255,0.08),
    inset 0 0 20px rgba(255,255,255,0.015);
```

Свечение должно быть практически незаметным.

Оно должно создавать ощущение настоящей стеклянной поверхности.

---

# BORDER

Используй тонкие границы:

```css
border: 1px solid rgba(255,255,255,0.10);
```

На hover:

```css
border-color: rgba(255,255,255,0.16);
```

Не используй толстые borders.

Не используй яркие белые рамки.

---

# ФОН

Сделай существующий фон более глубоким и премиальным.

Используй темный:

* графитовый;
* сине-зеленый;
* teal;
* очень темный серо-зеленый.

Добавь **очень мягкие размытые ambient gradients** позади существующих элементов.

Например:

```css
background:
    radial-gradient(
        circle at 15% 20%,
        rgba(39, 174, 150, 0.14),
        transparent 32%
    ),
    radial-gradient(
        circle at 85% 10%,
        rgba(80, 130, 220, 0.10),
        transparent 30%
    ),
    #10191b;
```

Градиенты должны находиться **на заднем плане** и не мешать читаемости.

# HOVER И MICRO-INTERACTIONS

Не добавляй новые интерактивные элементы.

Но существующим интерактивным элементам добавь современные состояния:

```css

    background .2s ease,
    border-color .2s ease,
    box-shadow .2s ease,
    transform .2s ease;
```

Для карточек допустимо:

```css

```

Очень аккуратно.

Никаких чрезмерных анимаций.
