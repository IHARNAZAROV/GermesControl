# GermesControl

## Что это
Desktop-приложение на Electron для АН «ГермесГарант»: сверяет объекты недвижимости
между тремя источниками (Сайт JSON, ILVO CRM XLSX, Kufar), находит расхождения
и проблемы с договорами.

## Технологии
Electron + чистый HTML/CSS/JavaScript (ES-модули в рендерере, без бандлера,
без React/Vue/Bootstrap/Tailwind). Файловое хранилище (`data/`) вместо SQL БД,
настройки — через `electron-store`. Библиотеки: `xlsx`, `fast-xml-parser`,
`fs-extra`, `dayjs`, `pdfkit`.

## Важно: как это запускать
Это **desktop GUI-приложение**, оно не открывается в Replit Preview (там нет
графического дисплея). Пользователь тестирует его локально: `npm install && npm start`.
В этом воркспейсе нет и не должно быть workflow с `npm start` — он не отработает.

## Структура
- `main.js` / `preload.js` — точка входа Electron и мост IPC.
- `src/main/` — бизнес-логика: `schema.js` (общая схема полей/ошибок),
  `sampleData.js` (генератор демо-данных), `parsers.js` (импорт XLSX/JSON/XML),
  `compare.js` (сравнение источников → статусы/ошибки/статистика),
  `reports.js` (экспорт отчётов XLSX/CSV/JSON/PDF), `dataStore.js` (файловое
  хранилище состояния в `data/` + electron-store), `ipcHandlers.js` (все
  `ipcMain.handle`).
- `render/` — интерфейс: `index.html`, `css/{base,layout,components,views}.css`,
  `js/app.js` (роутер + sidebar/topbar), `js/views/*` (8 разделов), `js/components/*`
  (таблица, donut/line-график, модалки, панель импорта, прогресс проверки).
- `data/` — создаётся при первом запуске (демо-данные), `.gitignore`'ится кроме
  `.gitkeep`.

## Текущий статус
Первая полнофункциональная версия по ТЗ пользователя: 8 разделов (Главная,
Объекты, Договоры, Сравнение площадок, Ошибки, Аналитика, Отчёты, Настройки),
реальный (не мокнутый) движок сравнения источников, ручной импорт файлов через
диалоги Electron, экспорт отчётов в 4 форматах. Реальной интеграции с API
ILVO/Kufar нет — по ТЗ на этом этапе импорт исключительно ручной.

Проверено логикой (Node-скрипты вне Electron, т.к. GUI недоступен в Replit):
генерация демо-данных, движок сравнения, парсинг XLSX/JSON/XML, генерация всех
форматов отчётов. Полный визуальный прогон интерфейса пользователь делает у себя.
