# GermesControl

Desktop-приложение для АН «ГермесГарант»: контроль объектов недвижимости, договоров
и рекламных выгрузок между тремя источниками данных — сайтом компании, ILVO CRM и
рекламной площадкой Kufar.

Стек: **Electron + чистый JavaScript/HTML/CSS** (без React/Vue/Bootstrap/Tailwind,
без SQL-баз данных — данные хранятся в файлах JSON/XLSX/XML внутри `data/`).

## Запуск

Приложение — desktop-GUI на Electron, ему нужен настоящий дисплей, поэтому оно
**не запускается в браузерном превью Replit**. Проверяйте его на своей машине:

```bash
npm install
npm start
```

## Источники данных

| Источник              | Формат | Способ загрузки          |
|------------------------|--------|---------------------------|
| Сайт ГермесГарант      | JSON   | автоматически по URL (также доступен файл) |
| ILVO CRM               | XLSX   | вручную, файл             |
| Kufar                  | XML    | вручную (файл или ссылка) |

Реальная интеграция с API ILVO/Kufar не реализована намеренно (по ТЗ) — для них
используется ручной импорт. JSON сайта автоматически загружается по адресу
`https://germesgarant.by/data/objects.json`; архитектура (`src/main/parsers.js`, `src/main/ipcHandlers.js`)
готова к тому, чтобы позже подключить автоматическую выгрузку.

Ожидаемый формат полей одинаков для всех источников: `id, title, type, dealType,
city, address, price, priceUsd, rooms, totalArea, livingArea, kitchenArea, floor,
floors, description, contractNumber, status`. В «Настройках» есть кнопка «Скачать
примеры файлов», которая генерирует образцы `.json/.xlsx/.xml` в этом формате.
Для JSON сайта статус `status.type = "sold"` и `status.date` означают, что объект
снят с продажи: его отсутствие на других площадках не считается ошибкой, а дата
показывается в реестре объектов.

## Структура проекта

```
main.js                 — точка входа Electron (главный процесс)
preload.js               — contextBridge API для рендерера
src/main/                — бизнес-логика главного процесса
  schema.js               общая схема объекта, типы ошибок
  sampleData.js           генератор демо-набора данных (первый запуск)
  parsers.js              разбор XLSX / JSON / XML источников
  compare.js              сравнение источников, поиск ошибок и статистики
  reports.js              генерация XLSX-отчётов с расширенными колонками,
                          сводкой и цветными диаграммами
  dataStore.js            файловое хранилище (data/) + electron-store для настроек
  ipcHandlers.js          IPC-обработчики между рендерером и главным процессом
render/                  — интерфейс (vanilla JS, ES-модули, без сборщика)
  index.html, css/, js/views, js/components
data/                     — рабочие данные приложения (создаётся при первом запуске);
                           в uploads хранится не более 5 последних файлов каждого источника
```

## Демо-данные

При первом запуске приложение автоматически создаёт демонстрационный набор данных
(с намеренными расхождениями и отсутствующими объектами), чтобы Dashboard и все
разделы сразу были содержательными.
